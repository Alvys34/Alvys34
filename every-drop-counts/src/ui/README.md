# src/ui — the player-facing shell (owner: UI)

Plain DOM overlay over the WebGL canvas, no framework. `createUI(...)` in `index.js` owns the app
state machine; `src/main.js` only constructs systems and forwards the loop:

```js
const simBus = createSimBus(bus);                 // ui/attract.js — gated bus for attract mode
const sim = createSim({ RAPIER, bus: simBus, seed });
const ui = createUI({ root, bus, simBus, sim, view, loop, input, audio: safeAudio, canvas, params, debug });
loop: onFrameStart -> ui.frame(realDt);  render -> view.update(...); ui.update(realDt)
audio.update(dt, { screen: ui.audioScreen, ...ui.audioState(sim.audioState()) })
ui.boot({ autostart })   // boot splash, or straight into a run (?autostart=N|overtime)
```

## Flow

```
boot splash (any button: audio unlock + fullscreen gesture)
  └─ title ─┬─ Clock in ───────────────┐
            ├─ Shift select ─ shift N ─┤→ briefing (level loaded silently, hazards visible) → play
            ├─ Overtime (after shift 3)┘
            ├─ Records (commendations, lifetime stats, Overtime top-10)
            ├─ Settings · Credits (+ third-party licences) · Quit (desktop only)
play ─ Esc/P/Start → pause ─┬─ resume · restart · settings · quit to menu (confirm)
     ─ hold R/Select → restart          (focus loss / hidden tab → pause)
     ─ shift:end (+1.8 s) → shift report ─ next (briefing) · retry · shift select
                                          └ shift 8 cleared: "Clock out" → ending sting → credits → title
     ─ Overtime tank dry → Overtime report (+ initials if top-10) ─ retry · main menu
```

Menus run the real sim in **attract mode** (`attract.js`: no hazards, immortal donors, the drum
gently rocked). The sim emits through a gated bus that is closed in menus, so attract events never
reach audio, VFX or the achievement tracker; the UI taps `donor:speak` for speech bubbles.

## Files

| File | What |
|---|---|
| `index.js` | app shell: modes, runs, results recording, teaching prompts, toasts, focus-loss pause |
| `nav.js` | screen stack + spatial focus navigation (keys / d-pad / stick / mouse), `ui:hover/click/back` |
| `screens.js` | boot, title, shift select, briefing, pause, settings, records, credits, confirm dialog |

| `bubbles.js` | donor speech bubbles projected from sim head positions |

| `attract.js` | gated sim bus + attract level/driver |
| `glyphs.js` | keyboard / gamepad button glyphs that follow the last-used device |
| `icons.js` | custom SVG pictograms + DRAINWELL logo mark |
| `copy.js` | every UI string (the DRAINWELL voice) |
| `licenses.js` | GENERATED by `tools/gen-licenses.mjs` from installed dependencies |

## Hooks other systems can provide (all optional, feature-detected — all present as of the integration pass)

* Render: `view.setScreenShake(scale 0..1)`, `view.setBloodColor('red'|'green')` (or
  `view.setBloodTint(hex)`), `view.setReduceFlashing(bool)`, `view.setQuality('auto')` returning
  true if VFX handles auto itself. Fallback: `view.ctx.settings.{screenShake, shakeScale,
  bloodColor, reduceFlashing}` are kept up to date.
* Ending camera: `view.playEnding()` (camera drifts into the intake hatch; returns false unless the
  shift has ended, then the CSS push-in fallback runs); `view.stopEnding()` on the way to the credits.
  The UI also emits `ending:start {}` on the bus.
* HUD footprint: `createHud({ onInsets })` reports the top-corner plates (viewport fractions) every
  0.5 s / on resize / on show-hide; `index.js` forwards them to `view.setHudInsets()` so the camera
  keeps drum corners out from under the plates. Below 2:1 the plates are compact (`ui.css`).
* PA ticker: lines that name keyboard keys ("Hold A / D to …", "Press SPACE to …") are shown as
  "Please rotate the drum. …" / "Please SLAM the drum. …" (`hud.js stripKeyNames`) — the bottom prompt
  already teaches the control with a device-aware glyph. CONTENT may rephrase the source lines later.
* Audio: `audio.warmup(ms)` (non-contract) is called when a shift starts so the sound bank never
  synthesises during play. Reset progress also restarts the achievement tracker (`systems.reloadAchievements`).
* Levels: `level.briefing` (one sentence) + `level.briefingIcon` (icon name from `icons.js`),
  `level.teach: ['rotate','slam','brake']` override the built-in briefing/teaching per shift.
* Achievements: `src/core/achievements.js` (`ACHIEVEMENTS`, `createAchievementTracker`).
